# Vigira documentation

Vigira is a self-hosted monitoring and backup project for household devices. This site collects its architecture, protocol, and deployment decisions as the project develops.

## Technical reference

- [Architecture](./architecture.md): server responsibilities and the initial deployment model.
- [Agent protocol](./protocol.md): the versioned server/agent wire contract and module interfaces.
- [Deployment and recovery decisions](./decisions.md): recorded choices, current defaults, and deferred questions.
- [Docker deployment](./deployment/docker.md): run the server and PostgreSQL with Docker Compose.

The project is under active development. These documents describe the current design baseline and do not imply that planned features are already available.
